Jede Farbe ist ein eigenes Päckchen, also ein eigenes Netz. Dick umrandet: das Päckchen und die Stellung, auf der die Klappe gerade steht.

Dürfen die beiden direkt reden?

Beide Rechner benutzen die Maske von oben. Jeder schaut durch seine Maske: gleiches Päckchen oder nicht?

Binär zeigen: die UND-Verknüpfung

UND heißt: Nur wo IP und Maske eine 1 haben, bleibt eine 1 stehen. Die Maske schneidet so den Hostanteil weg, übrig bleibt die Netz-ID.

Ausblick: Hier geht es weiter, wenn das Paket beim Router ankommt. Der Router stellt dieselbe Frage wie der Rechner, nur für jede Zeile seiner Tabelle.

Jede Zeile ist eine Schablone. Das Paket wird von grob nach fein an alle gehalten.

Zoom: von grob nach fein

Jede Zeile der Tabelle ist ein Kasten. Je mehr Blätter festgeklebt sind, desto kleiner und genauer der Ort. Das Paket fällt so tief hinein, wie es passt.

Kürzen und Aufklappen

Gib eine Adresse ein, lang oder gekürzt. Das Tool zeigt beide Richtungen.

Regel 1: Führende Nullen in einer Gruppe dürfen weg. Regel 2: Einmal dürfen mehrere Nullgruppen am Stück zu :: werden, sonst weiß niemand, wie viele Nullgruppen wohin gehören.
